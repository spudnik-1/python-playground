# python-playground

1. Install git on your machine.
1. Create a GitHub account.
1. Get **spudnik-1** to add your GitHub user to the repository as a collaborator. This will allow you to make changes here.
1. Run  `git config --global user.email "you@example.com"` and `git config --global user.name "Your Name"`. This tells git who you are.
1. `cd` to your `code` directory.
1. Run `git clone https://github.com/spudnik-1/python-playground.git`. This copies the repository that is in GitHub to your machine.
1. `cd` to `python-playground`.
1. Run `git switch -c my-branch`. This creates a branch called `my-branch`.
1. Open the `python-playground` directory in VS Code.
1. Implement the functions in `complete_me.py`.
1. Run the tests in `complete_me_test.py` to make sure your code works.
1. Run `git add complete_me.py`. This tells git to "stage" your file (i.e. include it in your next commit).
1. Run `git commit -m "Did some work."`. This creates a snapshot of your changes with a helpful commit message, indicated by `-m`.
1. Run `git push origin my-branch`.
1. Go to the repo in GitHub and createa pull request for **spudnik-1** to review and merge into the master branch.
1. Have a cookie :)
